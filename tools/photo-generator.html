← Ares Pantheon Photo Generator

Generates new product photography with OpenAI's image API, matched to the brand's existing gym-editorial style. Internal tool — not linked from the storefront.

How this works: this site is static (GitHub Pages, no server), so there is nowhere safe to store a shared API key. Instead, your own OpenAI API key stays in your browser only — saved to this browser's local storage if you opt in, sent directly from your browser to OpenAI's API, and never seen by this repository or any server. Don't share this page's URL or your key. Each generation is billed to your OpenAI account.

Publishing a generated photo to the live site:
  1. Click Download on the photo you want to keep.
  2. Move the downloaded file into assets/images/ in this repo, using the suggested filename.
  3. Click Copy <img> tag and paste it (or the file path) into the relevant product block in index.html, including its data-images list for the modal gallery.
  4. Commit and push.
